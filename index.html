Hermes Agent

Hermes Agent is a private automation assistant used by PGB Partners. It runs on the owner's own computers and works only with the Google account that the owner signs in with.

What it does

  • Saves work files that the owner produces (reports, maps, data tables) to the owner's own Google Drive folders.
  • Checks that an uploaded file arrived intact (name, size, checksum).
  • Sends a short notification with the file location to the owner's team Slack channel.
  • Runs scheduled personal tasks for the owner, such as preparing daily briefs.

Who can use it

Hermes Agent is not offered to the public. It is used only by its owner and the owner's own AI assistants (Hermes, Claude Code, Codex) on the owner's devices. There is no sign-up, no advertising and no paid plan.

Google user data

Hermes Agent requests only the Google permissions shown on the consent screen and uses them only for the features above. Currently it uses drive.file (access only to files the app itself creates or the user opens with it) and, for upload checks, drive.readonly. Google user data is not sold, shared with third parties or used for advertising. See the Privacy Policy for details.

Hermes Agent 소개

Hermes Agent는 PGB Partners가 사용하는 비공개 업무 자동화 도우미입니다. 소유자의 PC에서 실행되며, 소유자가 로그인한 본인 Google 계정에서만 동작합니다.

  • 소유자가 만든 업무 파일(보고서, 도면, 데이터 표)을 소유자 본인의 Google Drive 폴더에 저장합니다.
  • 올린 파일이 손상 없이 저장됐는지 이름·크기·체크섬으로 확인합니다.
  • 파일 위치를 소유자 팀의 Slack 채널에 짧게 알립니다.
  • 일일 브리프 준비 같은 소유자의 정기 작업을 실행합니다.

일반에 제공하는 서비스가 아니며 가입·광고·유료 기능이 없습니다. Google 사용자 데이터는 판매·제3자 제공·광고에 쓰지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.
