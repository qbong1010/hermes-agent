# Hermes Agent

Public home page, privacy policy and terms of service for **Hermes Agent**, a private automation assistant operated by PGB Partners. These pages back the Google Cloud OAuth consent screen (branding: home page, privacy policy, terms of service).

- Home: https://qbong1010.github.io/hermes-agent/
- Privacy Policy: https://qbong1010.github.io/hermes-agent/privacy.html
- Terms of Service: https://qbong1010.github.io/hermes-agent/terms.html

When Hermes Agent starts using a new Google scope, add it to the scope table in `privacy.html` (English and Korean sections) before requesting it.
